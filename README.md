
# DataPulse – Admin Analytics Dashboard

A responsive admin dashboard built using HTML5 and CSS3.

## Features

- Sidebar navigation
- Dashboard overview
- Four statistic cards
- Revenue overview chart
- Customer growth chart
- Recent transactions table
- Responsive layout for desktop, tablet and mobile

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## How to Run

1. Clone or download this repository.
2. Open the folder in VS Code.
3. Open index.html using Live Server.

## JavaScript

JavaScript is not used. This project is built using HTML and CSS only.
